# VoxFlow — голосовой ввод для Windows 🎙

Зажмите **Ctrl + Win** в любой программе, продиктуйте на русском или английском,
отпустите — текст со знаками препинания вставится туда, где стоит курсор.

## Скачать

**[⬇ Последняя версия — здесь](../../releases/latest)** → файл `VoxFlow-Setup-*.exe`

## Установка

1. Запустите установщик. Права администратора не нужны.
   Если Windows SmartScreen предупреждает: «Подробнее» → «Выполнить в любом случае»
   (установщик не подписан цифровой подписью — она платная).
2. При первом запуске вставьте бесплатный ключ [Groq](https://console.groq.com/keys)
   — или файл ключа `voxflow-key.vfk`, если владелец программы вам его дал
   (кнопка «У меня есть файл ключа»).
3. Готово: программа живёт в трее и запускается вместе с Windows.

## Возможности

- Распознавание русского и английского с пунктуацией и умной чисткой «слов-паразитов».
- Стили оформления текста + режим переводчика (English / 中文).
- Работает и без интернета — локальный движок распознавания.
- История диктовок, статистика, личный словарь терминов.

*Здесь публикуются только готовые установщики. Исходный код — в приватном репозитории автора.*
